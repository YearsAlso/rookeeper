# rookeeper Phase 0 协议基线

## 1. 设计目标

V1.0 使用长度前缀的轻量二进制协议，优先服务本地 IPC，并为未来迁移到本地 TCP、共享内存或加密传输保留扩展位。

## 2. 帧格式

每个请求/响应帧由固定长度头和可变长度载荷组成。

### 2.1 帧头

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | `u16` | 协议版本，当前为 1 |
| `request_kind` | `u16` | 请求类型 |
| `flags` | `u16` | 压缩、认证、追踪等扩展标记 |
| `reserved` | `u16` | 保留位 |
| `request_id` | `u32` | 请求标识 |
| `session_id` | `u64` | 会话标识 |
| `payload_len` | `u32` | 载荷长度 |

帧头固定长度为 **24 字节**。

## 3. 首批请求类型

| 类型 | 说明 |
| --- | --- |
| `Get` | 读取节点 |
| `Create` | 创建节点 |
| `Set` | 更新节点 |
| `Delete` | 删除节点 |
| `List` | 列举子节点 |
| `Watch` | 注册订阅 |
| `AcquireLock` | 获取锁 |
| `ReleaseLock` | 释放锁 |
| `RegisterService` | 注册服务实例 |
| `GetStatus` | 读取服务状态 |

## 4. 错误码基线

| 错误码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 路径不存在 |
| `2` | 路径已存在 |
| `3` | 版本冲突 |
| `4` | 权限不足 |
| `5` | 路径非法 |
| `6` | 会话失效 |
| `7` | 锁忙 |
| `8` | 资源不足 |
| `9` | 存储损坏 |
| `10` | 传输不可用 |
| `11` | 协议版本不支持 |
| `255` | 内部错误 |

## 5. 事件类型基线

| 事件 | 说明 |
| --- | --- |
| `NodeCreated` | 节点创建 |
| `NodeUpdated` | 节点更新 |
| `NodeDeleted` | 节点删除 |
| `ChildrenChanged` | 子节点变更 |
| `LockAcquired` | 锁获取 |
| `LockReleased` | 锁释放 |
| `ServiceRegistered` | 服务实例注册 |
| `ServiceUnregistered` | 服务实例注销 |

## 6. 扩展策略

1. `flags` 字段用于后续认证、压缩、加密协商。
1. `reserved` 字段保持为 0，未来可以引入分片、校验或 tracing 扩展。
1. 请求/响应头保持稳定，行为扩展优先通过新增请求类型和载荷结构完成。
